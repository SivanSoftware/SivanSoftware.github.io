# סיון לסרי — פורטפוליו

אתר פורטפוליו אישי בנוי עם [Next.js](https://nextjs.org) ו-Tailwind CSS, בעברית (RTL) ורספונסיבי למובייל.

**האתר החי:** https://sivansoftware.github.io/

## הרצה מקומית

```bash
npm install
npm run dev
```

ואז לפתוח את [http://localhost:3000](http://localhost:3000).

## פריסה

כל push ל-`main` בונה את האתר (יצוא סטטי, `next build`) ומפרסם אותו ל-GitHub Pages דרך GitHub Actions (`.github/workflows/deploy.yml`).
