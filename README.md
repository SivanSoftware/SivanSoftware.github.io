# Sivan Lasri — Portfolio

A personal portfolio website built with [Next.js](https://nextjs.org) and Tailwind CSS — bilingual (Hebrew RTL / English LTR), dark mode, and fully responsive.

**Live site:** https://sivansoftware.github.io/

## Features

- Bilingual Hebrew (RTL) / English (LTR) with a one-click language toggle
- Light & dark mode (remembers your preference, respects system setting)
- Interactive project showcase with per-project artwork and animations
- Experience timeline, skills, CV download, and contact links
- Static export deployed to GitHub Pages

## Tech stack

Next.js · React · TypeScript · Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Deployment

Every push to `main` builds the site (static export, `next build`) and publishes it to GitHub Pages via GitHub Actions (`.github/workflows/deploy.yml`).
